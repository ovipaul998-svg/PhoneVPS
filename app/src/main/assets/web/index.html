Waiting for Termux setup.
Required one-time setup
  1. Install and open Termux (prefer the official F-Droid or GitHub build).
  2. In Termux, run mkdir -p ~/.termux && echo 'allow-external-apps = true' >> ~/.termux/termux.properties, then restart Termux.
  3. Android Settings → Apps → PhoneVPS → Permissions → Additional permissions → allow Run commands in Termux environment.
  4. Disable battery optimization for Termux. For automatic startup after reboot, install and open Termux:Boot.

Background hosting is not guaranteed 24/7. Android may stop processes due to battery controls, overheating, low memory or network changes.
