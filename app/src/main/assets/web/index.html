What this version really supports

One shared projects folder is used by the file manager, terminal, Rust HTTP server, and Python runtime. You can switch between Rust Native and Python 3.11 at any time. The web server listens on your phone network interface so devices on the same Wi-Fi may reach it using your phone’s LAN IP and configured port. This is still an Android userspace, not full Ubuntu: apt, arbitrary Linux binaries, npm/Node.js, public internet access and guaranteed 24/7 uptime are not included.
