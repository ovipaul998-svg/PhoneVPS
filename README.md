# PhoneVPS

PhoneVPS is an Android dashboard project for managing a local phone-based development environment.

## Current status

This repository is being initialized. The first release is a dashboard shell; it does not yet provide a real Ubuntu virtual machine, 24/7 hosting, or a production terminal/server manager.

## Planned features

- Dark professional dashboard
- Python and Node.js project management
- Discord bot process management
- File manager and terminal interface
- Resource monitoring
- Startup controls

## Build

The Android app project and GitHub Actions APK build workflow will be added in the next commit.
